The following is a future plan, not work completed in this session. Hosted deployment is blocked until PostgreSQL, driver, production preconditions, privacy and branding have been reviewed. The existing code accepts synthetic Pilot sessions only and blocks Live; do not invite friends to provide real responses under that configuration.

1. Review this directory, `SHA256SUMS`, release audit, source, licenses, data exclusions and all staged paths. Confirm the repository will be private and obtain permission to use the SSE mark and stated contact. A temporary directory can be cleared by the OS: move the reviewed source to an approved durable location before use and rerun verification there.
2. On GitHub, **with researcher approval for external transmission**, create an empty private repository named `sse-powerplant-survey`; do not add a README, license, or gitignore remotely. Confirm the owner and visibility. Review the target before copying its SSH URL.
3. In the reviewed package run `shasum -a 256 -c SHA256SUMS`, `git status --short`, `git diff --cached --stat`, `git diff --cached` and `git ls-files`. If no local repository exists, run `git init -b main`, then `git add --all`. Review every staged file; `.gitignore` cannot remove previously committed data. Recheck for secrets, respondent data and unintended assets before committing.
4. After review, `git commit -m 'Prepare V4 survey release candidate'`. Do not commit actual answers or secret values.
5. **External transmission requires researcher approval:** `git remote add origin git@github.com:OWNER/sse-powerplant-survey.git` (replace OWNER with the verified GitHub account or organization), then `git push -u origin main`. Verify repository visibility and uploaded file list in GitHub.
