## Data-handling limits

Each submitted page is stored in raw oTree tables, including incomplete records. The completed-only export excludes them, not the raw database. With timing declined, research timing is excluded; initialization records, essential cookies, logs and provider metadata can still exist. Timing before consent is not exported. Optional feedback may contain identifying details despite the instruction not to include them. The deletion tool cannot erase external exports, logs, backups or processor copies, and the page-time buffer must be drained from **every** stopped worker before deletion. See `FINAL_DATA_DELETION_GUIDE.md`.
